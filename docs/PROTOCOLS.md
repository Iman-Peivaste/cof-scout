The archive preserves these immutable protocol families:

1. `ara5_reasoning_mcap_v1` — original COF-SCOUT and algorithmic controls.
2. `cof_scout_v2_extension` — superseded extension freeze, retained for audit.
3. `cof_scout_v2_extension_r2` — institutional-gateway extension conditions A–F.
4. `cof_scout_v2_extension_r2_c_amendment` — condition-C plumbing amendment.
5. `cof_scout_v2_identifier_relabel_control` — static identifier-permutation control.

The reusable inventory, reference landscape, oracle, 50-evaluation horizon, endpoint,
analysis code, tools and memory reconstruction remain tied to their recorded hashes.
The public configs omit private endpoints and credentials. For exact transmitted
sampling parameters, prompts, failures, and replacements, use the frozen manifests
and redacted traces in the data archive.
