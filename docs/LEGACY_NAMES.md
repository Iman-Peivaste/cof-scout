# Legacy internal names

The study developed through internal Ara and MCAP names. They remain only where
changing them would break frozen hashes or make a trace impossible to resolve.

| Legacy name | Public meaning |
|---|---|
| `ara5_*` | Original COF-SCOUT implementation and analysis |
| `ara5_reasoning_mcap_v1` | Frozen original COF-SCOUT study |
| `mcap` | Internal name for the prospective prediction/falsification contract |
| `ara5_mcap_full_rep*` | Original adaptive COF-SCOUT campaigns |
| `ara5_mcap_static_rep*` | Original static outcome-blind portfolios |
| `cof_scout_r2_[A-F]_rep*` | Extension-r2 conditions |

New public APIs use the `cof_scout` package name. Frozen artifacts and their hash
lists are never renamed or rewritten.
